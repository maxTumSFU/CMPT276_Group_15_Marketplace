
# Messaging System

## Overview
This iteration focused on improving the listing feature and making it easier for users to post items, view listings, and contact sellers.

## What We Implemented

### 1. Listing Photos
- Added support for uploading multiple photos for a listing.
- Added photo storage and display support.
- Created a photo gallery on the listing details page.
- Added a full-screen photo viewer with next and previous options.

### 2. Messaging
- Added a Message Seller option on listing pages.
- Created a messaging system between buyers and sellers.
- Added an inbox to view conversations.
- Added the ability to send and receive messages.
- Added message timestamps and unread notifications.
- Messages are saved in the database.

### 3. Page Styling
- Improved the styling of listing cards and listing details.
- Styled the photo gallery and full-screen photo viewer.
- Added styling for the messaging inbox and conversation pages.
- Improved buttons, forms, spacing, and page layouts.
